# structure internal tools

Internal tools for the [structure](https://structurefirm.com) consulting team. The wordmark is lowercase **structure**. The line under it is “Growth needs structure. We build it.”

These pages are for the team. They are separate from the client-facing owner tools.

## Tools

| Tool | File | What it is for |
| --- | --- | --- |
| The Team Assessment | [`team-assessment-tool.html`](team-assessment-tool.html) | Assessing a client’s people. It holds the activity map, self-input, the future org, the action plan, and the owner report. Use **Load a sample client** for Harbor & Pine Remodeling (fictional). |

Open them from [`index.html`](index.html).

## Where the data lives

Nothing you type is uploaded. Each tool keeps its work in the browser you are using. Download a file if you want a copy on another computer. On a shared computer, remove the assessment when you are done.

The team assessment does not connect to Notion, Google, or the Hub. Outside data comes in only when you open a JSON file. A separate skill can build that file. The shape is in [`SCHEMA.md`](SCHEMA.md). Do not put a real client’s data in this repo. Harbor & Pine Remodeling is fictional.

## The index

`index.html` lists the tools. It uses the same client-side access code as the owner tools index (`pivotyestools`). That code only hides the list in this browser for the rest of the session. It is not an account. Opening a tool file directly does not ask for the code, which is the same as the owner tools index.
